# Native adaptation record

The selected design is Instrument, composition B with the explanation content of C
inside Understand. The original planning record identified generated numeric
geometry, spacing and some legend colors as intentions rather than exact data
specifications. The first milestone uses native Android controls and one working
experiment.

## Preserved

The compact screen title, period control, common plot, solid lime/dashed cyan
series, amber cursor, attached readout and non-modal Adjust/Understand panel keep
the selected composition. Replay remains the primary experiment action. The
background and panel have been aligned to the reference's cooler green-black field.

## Platform and product adaptations

| Reference difference | Reason |
| --- | --- |
| System status and gesture bars | Android owns their metrics and contents. |
| Roboto and Material typography | Native type scale supports system font size. |
| Segment, slider, switch and button shapes | Material 3 supplies behavior, semantics and minimum touch targets. |
| Plot position and coordinates | Chart math determines real fixture positions, axes and selected values. |
| Readout text instead of decorative dots/dividers | Series names and units stay explicit; the chart also differentiates line patterns. |
| No overflow menu or panel drag handle | No menu or draggable sheet behavior is implemented; the panel has a close action. |
| One gallery entry | Only an implemented experiment is presented as available. |
| Scrolling in short windows or at large font sizes | Text and controls remain reachable rather than being compressed. |

## Review evidence

Local review evidence includes the approved generated reference, exact-size native
capture, paired regions, full phone/large-font/landscape captures and the original
concept-seed execution record. These are design-process evidence, not runtime assets.

The strict fixed-coordinate comparison finally reported **71.03%** (initially 69.73%), below its
72% gate. It classified several displaced native controls as missing even though
they are visible in the full frame and paired crops. The raw report is retained;
no force override or numeric pass is claimed. Native review explicitly examines
these adaptations and the actual interaction and semantic evidence separately.
The tool's open pixel-reproduction gate is a limitation of that comparison, not
an automated accessibility or functional verdict.

Independent final review resolved the surface palette, seed provenance, control
semantics and world quality-bar findings, with no material regression in the
required captures. Its disposition remains **fix** because the strict reproduction
gate is open. This is a functional native milestone, not a claimed pixel-identical
reproduction or an unqualified design approval.
